User Manual — Classes
What Are Classes?
Classes are the race categories you can nominate for at an event.
Each class represents a type of vehicle or racing category, such as:

1/8 Nitro Buggy

1/8 E‑Buggy

2WD Modified Buggy

Stadium Truck

Junior Classes

Vintage

Events may offer different classes depending on the track and the event format.

How Classes Work at Events
Classes Are Assigned Per Day
If an event runs over multiple days, each day may have different classes available.

Example:

Saturday: Nitro Buggy, E‑Buggy, Truggy

Sunday: Nitro Buggy, Junior, Vintage

You can only nominate classes that are available on the day you are racing.

Max Classes Per Driver
Each event sets a limit on how many classes you can nominate.

Example:

Code
Max Classes Per Driver: 2
This means you can choose up to two classes for that event.

If you try to select more than the limit, the system will stop you.

Preferences
Some events allow you to select preference classes.

Preferences let you indicate which classes you prefer to race in case the event has limited spots or needs to balance entries.

Preferences Allowed
If enabled, you will see a toggle or option to mark a class as a preference.

Preference Limit
Events may also set a limit on how many preferences you can choose.

Example:

Code
Preference Limit: 1
This means you can mark one of your selected classes as your preferred choice.

If preferences are disabled, you will not see any preference options.

How to Select Classes
Open the event nomination page

Choose the day you want to race (if multi‑day)

Select the classes you want to enter

If preferences are enabled, choose which class is your preference

Confirm your selections

Review your pricing and complete your nomination

Class Ordering
Classes may appear in a specific order.
This order is set by the event organisers and may reflect:

Race scheduling

Popularity

Track flow

Heat balancing

You do not need to worry about the order — it is for event management only.

Class Availability
You will only see classes that:

Are allowed at the track

Are assigned to the event

Are assigned to the specific day

Are currently available for nomination

If a class is missing, it means it is not offered for that event or day.

Common Questions
Can I race more than one class?
Yes — as long as the event’s class limit allows it.

Can I change my classes later?
Yes, until nominations close.

What happens if I select a preference?
Your preference helps organisers place you if entries are limited.

Do preferences cost extra?
Some events may charge for preferences depending on the pricing mode.

Why don’t I see all classes?
Only classes allowed at the track and assigned to the event will appear.

Summary
Classes are the categories you race in

Events may offer different classes per day

You can only select up to the event’s class limit

Preferences may be allowed and may have a limit

You will only see classes available for that event and track

You can change your classes until nominations close

This system ensures fair, organised, and flexible class selection for all drivers.
